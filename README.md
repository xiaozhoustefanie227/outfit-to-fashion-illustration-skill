# Outfit to Fashion Illustration Skill

A reusable image-generation skill for converting real outfit photos into minimalist fashion-editorial illustrations.

## Default Look

- Elegant black ink lines
- Sparse watercolor or gouache accents
- Accurate garment reconstruction
- Simplified facial features
- Ivory paper background
- Large negative space
- Minimal or omitted background
- Paris fashion-magazine sketch mood

## Quick Use

Upload an outfit photo and say:

- “用 outfit-to-fashion-illustration-skill”
- “把这套穿搭变成极简时装插画”
- “人物和穿搭不要变，背景去掉，做成时装手稿”
- “两个人都保留，做成时尚杂志插画”
